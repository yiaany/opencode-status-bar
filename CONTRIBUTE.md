# Contributing

Thanks for helping improve OpenCode Status Bar.

## Development

1. Fork the repository and create a focused branch.
2. Build with `./build.sh` or `./build.sh --dmg`.
3. Install the local plugin from `plugin/` in `opencode.jsonc`.
4. Start OpenCode, run a prompt, invoke a tool, and test a permission request.
5. Open a pull request with the motivation, test environment, and screenshots for UI changes.

Keep the macOS app dependency-free, do not store prompts or secrets, and preserve the third-party notices.
